تصميم وفكرة: أ. نعيمة سعيد الرشيدي

أولاً: التحديث على GitHub
ارفعي الملفات (index.html و sw.js و manifest.webmanifest ومجلد icons و supabase-setup.sql) فوق الملفات القديمة في مستودع haqiba.

ثانياً: ربط قاعدة البيانات Supabase (مرة واحدة)
1. ادخلي supabase.com وأنشئي مشروعاً جديداً (اختاري أقرب منطقة، مثل Frankfurt أو Bahrain إن وُجدت).
2. من SQL Editor: New query، والصقي محتوى ملف supabase-setup.sql كاملاً، ثم Run.
   - إن كان بريد الجامعة غير bu.edu.sa فغيّري bu.edu.sa في الملف قبل التشغيل.
3. من Authentication ← URL Configuration:
   Site URL: https://intilaqa.github.io/haqiba/
   Redirect URLs: أضيفي الرابط نفسه.
4. من Project Settings ← API انسخي: Project URL ومفتاح anon public.
5. افتحي index.html، وفي أعلاه ابحثي عن HAQIBA_CONFIG والصقي:
   supabaseUrl:"الرابط" , supabaseKey:"المفتاح"
   ثم ارفعي الملف على GitHub.
6. افتحي التطبيق وادخلي ببريدك الجامعي. أول دخول يرفع بيانات جهازك إلى قاعدة البيانات، لذلك:
   ابدئي من جهاز فيه البيانات التي تريدينها (استيراد جدول الفصل والتوصيفات)، لا من بيانات تجريبية.

ملاحظات:
- مفتاح anon public مصمم ليكون في التطبيق، والحماية في الصلاحيات (RLS) بملف SQL: لا يقرأ البيانات أو يعدلها إلا بريد جامعي.
- الطلاب يعبّئون الاستبيانات برابط بلا حساب، وتصل الردود فقط للاستبيانات المفتوحة.
- الملفات المرفوعة (الاختبارات، العينات، الأدلة) تُحفظ في مجلد خاص haqiba-files في Supabase.
- تجربة الربط دون تعديل الملف: الإعدادات ← قاعدة البيانات المشتركة (على جهازك فقط).

================ المساعد الذكي «اسألي الحقيبة» (اختياري) ================
يعمل المساعد فوراً دون أي إعداد: يجيب من معايير المركز الوطني المضمّنة (المعايير والمحكات، الوثائق المطلوبة،
الأهلية، مؤشرات الأداء، محطات الاعتماد) ومن أرقام برنامجك الآن.
لتفعيل الإجابات الذكية الكاملة (نموذج Claude) بعد ربط Supabase:
1. أنشئي مفتاح API من console.anthropic.com (الاستخدام مدفوع حسب عدد الأسئلة).
2. ثبّتي Supabase CLI ثم من مجلد هذه الحزمة:
   supabase login
   supabase link --project-ref <معرّف مشروعك>
   supabase secrets set ANTHROPIC_API_KEY=sk-ant-...
   supabase functions deploy haqiba-ai
   (الملف في supabase/functions/haqiba-ai/index.ts، ويمكن بدلاً من ذلك لصقه في Edge Functions من لوحة Supabase باسم haqiba-ai)
3. إن كان نطاق البريد الجامعي غير bu.edu.sa: supabase secrets set STAFF_DOMAIN=نطاقكم
بعدها يظهر في نافذة المساعد «المساعد الذكي متصل». لا تُرسل أسماء الطلاب ولا الأعضاء، فقط ملخص أرقام البرنامج.
